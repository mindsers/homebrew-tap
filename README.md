# mindsers/homebrew-tap

Homebrew formulae for things I maintain.

```console
$ brew install mindsers/tap/<formula>
```

`brew tap mindsers/tap` first if you would rather browse before installing.

## Formulae

| formula | what it is | source |
|---|---|---|
| `omh` | run any coding agent in a Docker sandbox with your rules, skills and MCP servers already inside | [mindsers/ohmyharness](https://github.com/mindsers/ohmyharness) |

## Where a fix belongs

**In the project, not here.** A formula describes software that lives in
another repository, and that repository is where bugs, features and questions
about the software itself get answered.

Some formulae here are **generated** — written by their project's release
pipeline whenever it tags a version. Editing one of those in this repository
works exactly until the next release overwrites it, so the change has to go to
the template upstream.

| formula | generated by | template |
|---|---|---|
| `omh` | the `release` workflow in `mindsers/ohmyharness` | [`packaging/homebrew/omh.rb.tmpl`](https://github.com/mindsers/ohmyharness/blob/main/packaging/homebrew/omh.rb.tmpl) |

Something wrong with the *tap itself* — a formula that will not install, a
checksum that does not match, a stale version — belongs here.

## What CI checks

`brew style` and `brew audit --strict` run on every push, over whatever
formulae are present. A weekly run adds `--online`, which re-fetches the URLs
and re-checks the checksums; that is the one that notices a release asset
changing or disappearing after the fact.
